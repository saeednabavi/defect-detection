# تشخیص عیب سطح

خط تولید مصنوعی: تصویر سالم در برابر خراش یا لکه. یک جنگل تصادفی روی ویژگی‌های سطح آموزش می‌بیند و از راه یک سرویس وب جواب می‌دهد.

```powershell
cd project\defect-detection
python train_eval.py
python app.py
```

سرویس روی `http://127.0.0.1:5061` است. روی ۲۰۰ تصویر آزمون: precision برابر ۱.۰۰، recall برابر ۰.۹۸، نرخ هشدار غلط ۰، و حدود ۰.۲ میلی‌ثانیه برای هر تصویر. اعداد در `models/metrics.json` نوشته می‌شود. تصویرها مصنوعی‌اند تا پروژه بدون دادهٔ کارخانه قابل انتشار باشد.
